# Antrian Barber v2.1e — Frontend QA Baseline

**Release type:** portfolio demonstration / frontend-only  
**Status:** tested local demo; not a production booking service.

## Included

- Multi-page customer interface with shared navigation.
- Responsive styling and accessible navigation controls.
- Service and barber selections, inspiration gallery.
- Four-step booking wizard with local tickets, persistence and cancellation.
- Playwright end-to-end test suite.

## Verification

- Manual acceptance tests: **10/10 passed** (developer-run).
- Playwright Chromium: **19/19 passed**.
- Lighthouse Home: **100 / 95 / 100 / 92**.
- Lighthouse Booking: **99 / 96 / 100 / 91**.

Scores are Performance / Accessibility / Best Practices / SEO. Lighthouse results are from local production preview; mobile/desktop mapping for each page remains to be documented.

## Known limitations

- Bookings and ticket numbers are restricted to the current browser's `localStorage`.
- No backend or shared PostgreSQL database, availability verification, or admin login.
- Barber profiles, availability, service prices and bookings are illustrative.
- No payment integrations or real customer notifications.

## Next milestone

v2.2 — FastAPI and PostgreSQL foundation, followed by centralized booking rules.
